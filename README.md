#### 🏫 [School Management System](https://github.com/mademohanvamsikrishna-prog/school-management-)
> A full-stack, multi-tenant academic and operational platform engineered for role-based school workflows.
- **Backend Architecture**: FastAPI REST API with SQLAlchemy ORM, Alembic schema migrations, and PostgreSQL/SQLite support.
- **Security & Authorization**: Granular RBAC with 27 permissions, JWT access & refresh token rotations, and record-ownership isolation across 4 key roles (*Admin, Teacher, Student, Parent*).
- **Core Modules**: Automated exam grading, schedule conflict detection, attendance tracking, sandbox financial invoices, library management, and leave approval workflows.
- **Reliability & Testing**: Backed by **79 unit & integration tests** in `pytest`. Dual-tier deployment configured for Vercel and Render.
- **Stack**: `TypeScript` • `React Native / Expo` • `Python` • `FastAPI` • `PostgreSQL` • `SQLAlchemy` • `Alembic` • `Pytest`
